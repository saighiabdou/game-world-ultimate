GAME WORLD ULTIMATE — VERSION 7 STARTER KIT

Files:

- backend/schema.sql: starter database schema for Supabase.

Do not collect payments or real customer data until secure server functions, payment validation, privacy/terms and testing are complete. Never expose a Supabase service-role key in frontend files.
